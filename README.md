# Retail Sales Analysis

Retail sales data analysis using Python and Jupyter Notebook.

## 📌 Project Overview

This project focuses on analyzing retail sales data using Python. The analysis is performed in a Jupyter Notebook to explore the dataset, perform data analysis, and generate useful visualizations and results.

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📓 Project File

* `Retail_sales_Analysis.ipynb` — Contains the complete retail sales data analysis, code, outputs, and visualizations.

## 📊 Analysis

The notebook contains the analysis of the retail sales dataset along with the generated outputs.

## ▶️ How to Run

1. Clone or download this repository.
2. Open `Retail_sales_Analysis.ipynb` using Jupyter Notebook, JupyterLab, or Google Colab.
3. Run the notebook cells to reproduce the analysis.

The notebook includes the outputs during the analysis.
